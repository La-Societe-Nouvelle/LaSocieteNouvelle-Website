Une fois les déclarations complétées, les résultats de l'analyse sont disponibles dans la vue **Tableau de bord** : une vue globale de l'empreinte sociétale de l'entreprise, et une vue détaillée pour chaque indicateur.

## Le tableau de bord

![Vue des résultats - Tableau de bord - Application Metriz](/screens-webapp-v4/screen-metriz-v4_tableau-de-bord.png "eager")

Pour chaque indicateur, le tableau de bord présente :

- l'**empreinte de la production** de l'entreprise ;
- la comparaison avec la **moyenne de la branche d'activité** ([données statistiques](/docs/donnees-statistiques)) ;
- la comparaison avec l'**objectif sectoriel 2030** ;
- une analyse générale et une analyse par indicateur (voir [Utilisation de l'IA](/docs/metriz-webapp/utilisation-ia)).

## Fixer un objectif personnalisé

Chaque indicateur dispose d'un objectif, visible dans l'onglet **Objectifs** de sa vue. Par défaut, il est **aligné sur l'objectif sectoriel à l'horizon 2030** (voir [Sources des données](/docs/donnees-statistiques/sources)). Il est possible de saisir un objectif propre à l'entreprise, pour suivre sa trajectoire dans le temps :

- un objectif personnalisé **remplace l'objectif sectoriel tant que son horizon n'est pas atteint** ;
- une fois l'horizon dépassé, l'objectif sectoriel s'applique de nouveau ;
- un objectif personnalisé est repéré par **un astérisque** dans le tableau des objectifs.
