L'application web **Metriz** fournit une solution de base pour la mesure de l'[Empreinte Sociétale](/docs/empreinte-societale) d'une Entreprise.

Elle fait le lien entre les **écritures comptables**, l'**analyse réalisée lors de l'exercice précédent**, les **données disponibles pour les fournisseurs** et les **impacts directs** de l'entreprise.

## Accéder à l'application

L'application est accessible à l'adresse suivante : [https://metriz.lasocietenouvelle.org](https://metriz.lasocietenouvelle.org)

<Callout type="note">

Metriz est mis à disposition gratuitement pour permettre la mesure de l'Empreinte Sociétale à toutes les entreprises. Pour soutenir son développement : [Devenir partenaire](/appel-partenariat)

</Callout>
