L'application web **Metriz** est mise à disposition pour fournir une solution de base pour la mesure de l'[Empreinte Sociétale](/docs/empreinte-societale) d'une Entreprise.

Elle fait le lien entre les **écritures comptables**, l'**analyse réalisée lors de l'exercice précédent**, les **données disponibles pour les fournisseurs** et les **impacts directs** de l'entreprise.

La version locale n'est plus maintenue.

## Accéder à l'application

L'application est accessible à l'adresse suivante : [https://metriz.lasocietenouvelle.org](https://metriz.lasocietenouvelle.org)
