## Initialiser une nouvelle analyse

<Callout type="note" title="Importer vos dossiers clients">

Si vous utilisez un logiciel comptable compatible, vous pouvez récupérer directement la liste de vos dossiers clients depuis un [connecteur](/docs/metriz-webapp/integrations) (ACD, Inqom, MyUnisoft, Pennylane, Tiime).

</Callout>

<Screens items={[
    { src: '/screens-webapp-v4/screen-metriz-v4_ajouter-une-entreprise-curseur.png', alt: "Bouton d'ajout d'une unité légale - Application Metriz", caption: "Ajouter une unité légale" },
    { src: '/screens-webapp-v4/screen-metriz-v4_ajouter-une-entreprise-modale-vue-entiere.png', alt: "Formulaire d'ajout d'une entreprise - Application Metriz", caption: "Saisie du numéro SIREN" },
]} />

<Steps>

<Step>

Cliquez sur **Ajouter une unité légale**

</Step>

<Step>

Saisissez le **numéro SIREN** de l'entreprise (numéro à 9 chiffres)

</Step>

<Step>

L'entreprise apparaît dans la liste des dossiers

</Step>

</Steps>

<Callout type="tip" title="En cas de difficulté">

Si le numéro SIREN n'est pas reconnu, prenez contact avec le support.

</Callout>

## Lancer la nouvelle analyse

![Menu de lancement d'une nouvelle analyse - Application Metriz](/screens-webapp-v4/screen-metriz-v4_commencer-analyse-menu.png)

Une fois l'entreprise ajoutée :

<Steps>

<Step>

Cliquez sur **Nouvelle analyse**

</Step>

<Step>

L'analyse démarre et vous accédez à l'import du FEC

</Step>

</Steps>
