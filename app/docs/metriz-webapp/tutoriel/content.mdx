Le parcours manuel décrit chaque étape d'une analyse dans l'application METRIZ. Pour enchaîner automatiquement les étapes de configuration, voir le [démarrage rapide](/docs/metriz-webapp/analyse-rapide).

## Les étapes

| Étape | Ce que vous faites | Guide |
|---|---|---|
| 0 | Créer votre compte | [Créer son compte](/docs/metriz-webapp/creer-un-compte) |
| 1 | Créer l'unité légale et lancer l'analyse | [Créer une unité légale](/docs/metriz-webapp/creer-unite-legale) |
| 2 | Importer le FEC et vérifier les données comptables | [Importer le FEC](/docs/metriz-webapp/importer-le-fec) |
| 3 | Associer les immobilisations et leurs fournisseurs | [Catégoriser les immobilisations](/docs/metriz-webapp/immobilisations) |
| 4 | Associer les achats et leurs fournisseurs | [Catégoriser les achats](/docs/metriz-webapp/achats) |
| 5 | Déclarer les impacts directs | [Déclarer les impacts directs](/docs/metriz-webapp/declarer-impacts-directs) |
| 6 | Lire les résultats | [Consulter les résultats](/docs/metriz-webapp/consulter-les-resultats) |

## Avant de commencer

Rassemblez les données nécessaires : voir les [prérequis](/docs/metriz-webapp/informations-necessaires).

## Pour comprendre ce que fait chaque étape

La page [Étapes de calcul](/docs/metriz-webapp/etapes-de-calcul) explique la logique de la méthode, et [Utilisation de l'IA](/docs/metriz-webapp/utilisation-ia) détaille les usages de l'IA générative.
