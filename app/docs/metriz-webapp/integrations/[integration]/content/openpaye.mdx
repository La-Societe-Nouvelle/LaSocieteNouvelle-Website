## Intégation OpenPaye 

L'integration est disponible pour l'ensemble des utilisateurs, sur simple demande auprès du support technique.

### Services 

L'intégration avec OpenPaye permet la récupération des données sociales.

### Connexion

La connexion à OpenPaye via Metriz se fait à partir de l'identifiant et du mot de passe API (accessible depuis l'espace OpenPaye).
