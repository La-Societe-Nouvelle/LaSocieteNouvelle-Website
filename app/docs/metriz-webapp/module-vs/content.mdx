Le module de base VS est un complément à la mesure de l'empreinte sociétale. Il reprend les données déclarées dans Metriz pour alimenter les informations de durabilité de l'entreprise : informations générales, environnement, social et gouvernance.

![Module de base VS - Application Metriz](/screens-webapp-v4/screen-metriz-v4_reporting-vs.png)

## Fonctionnement

- Les valeurs sont **pré-remplies** à partir des déclarations d'impacts directs, et restent modifiables.
- Les saisies sont **enregistrées automatiquement**.
- Les résultats peuvent être **exportés au format .xlsx**.
