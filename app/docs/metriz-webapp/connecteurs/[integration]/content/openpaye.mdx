Le connecteur est disponible pour l'ensemble des utilisateurs, **sur simple demande auprès du support technique** (voir [Activer un connecteur](/docs/metriz-webapp/connecteurs#activer-un-connecteur)).

## Services

Le connecteur OpenPaye permet d'importer les **DSN** directement, sans téléverser les fichiers. Elles sont ensuite lues comme un fichier téléversé (voir [Lecture des DSN](/docs/metriz-webapp/lecture-dsn)).

## Connexion

La connexion à OpenPaye via Metriz se fait à partir de l'identifiant et du mot de passe API (accessible depuis l'espace OpenPaye).

## Importer les DSN

Dans la fenêtre **Gestion des données sociales**, onglet **Import des DSN**, cliquez sur **Importer via OpenPaye**. Un assistant guide l'import en 3 étapes : choix du **dossier**, de l'**établissement**, puis **import** des déclarations.
