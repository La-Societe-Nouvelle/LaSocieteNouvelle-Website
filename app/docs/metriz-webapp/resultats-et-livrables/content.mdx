Une fois les déclarations complétées, Metriz propose plusieurs espaces pour exploiter les résultats.

## Tableau de bord

Le tableau de bord présente, pour chaque indicateur :

- la valeur mesurée de l'empreinte de la production ;
- la comparaison avec la moyenne de la branche d'activité ([données statistiques](/docs/donnees-statistiques)) ;
- les objectifs à atteindre ;
- une analyse générale et une analyse par indicateur (voir [Utilisation de l'IA](/docs/metriz-webapp/utilisation-ia)).

## Objectifs personnalisés

Chaque indicateur dispose d'un objectif. Par défaut, il est **aligné sur l'objectif sectoriel à l'horizon 2030** (voir [Sources des données](/docs/donnees-statistiques/sources)). Il est possible de saisir un objectif propre à l'entreprise :

- un objectif personnalisé **remplace l'objectif sectoriel tant que son horizon n'est pas atteint** ;
- une fois l'horizon dépassé, l'objectif sectoriel s'applique de nouveau ;
- un objectif personnalisé est repéré par **un astérisque** dans le tableau des objectifs.

## Module de base VS

![Module de base VS - Application Metriz](/screens-webapp-v4/screen-metriz-v4_reporting-vs.png)

Le module de base VS reprend les données déclarées pour alimenter les informations de durabilité (informations générales, environnement, social, gouvernance). Les valeurs pré-remplies à partir des déclarations restent modifiables, et les saisies sont enregistrées automatiquement. Les résultats peuvent être exportés au format .xlsx.

## Livrables

Les résultats peuvent être exportés sous forme de rapports (PDF, PPTX) et de données. Les contenus de l'export (indicateurs, objectifs, comparaisons) sont configurables avant la génération.

## Publication

![Page de publication - Application Metriz](/screens-webapp-v4/screen-metriz-v4_publication.png)

La publication de l'empreinte sociétale dans la base de données ouverte se fait depuis l'espace **Publication**, de deux façons : par un bon de publication téléchargé puis envoyé par e-mail, ou par une **demande en ligne (recommandée)** où l'on sélectionne les indicateurs à publier.
