Les données d'impacts utilisées varient selon les indicateurs. Elles alimentent les vecteurs d'impacts décrits dans la [méthodologie](/docs/donnees-statistiques/methodologie#vecteurs-d-impacts).

Les objectifs utilisés pour les trajectoires cibles varient également selon les indicateurs. Les trajectoires cibles alimentent le jeu de données [macro_fpt_tgt](/docs/donnees-statistiques/jeux-de-donnees/macro_fpt_tgt). Elles sont disponibles pour **8 des 12 indicateurs**.

Chaque page indicateur présente les **comptes d'impacts directs** et, le cas échéant, les **objectifs 2030**.
