## Présentation

Le jeu de données `macro_fpt` regroupe les empreintes des activités économiques selon la nomenclature FIGARO (A*64).

Les empreintes sont disponibles pour les agrégats suivants :

| Code | Agrégat |
|---|---|
| `PRD` | Production |
| `GVA` | Valeur ajoutée brute |
| `IC` | Consommations intermédiaires |
| `NVA` | Valeur ajoutée nette |
| `CFC` | Consommations de capital fixe |

Les dimensions extra-financières disponibles sont celles de l'[Empreinte Sociétale](/docs/empreinte-societale/indicateurs).

La période d'observation couvre de 2010 à 2023, selon la dimension sociale ou environnementale.

Les empreintes sont exprimées **en euros courants**, et **dans l'unité par défaut de l'indicateur**.

## Description de la table

| Colonne | Type | Description |
|---|---|---|
| `indic` | Paramètre | Code de l'indicateur au sein de l'Empreinte Sociétale |
| `year` | Paramètre | Année |
| `country` | Paramètre | Code du pays (ISO3) ou région du monde |
| `industry` | Paramètre | Code du secteur, selon la NACE Révision 2 (codes A64, A21 et A10) |
| `aggregate` | Paramètre | Code de l'agrégat économique |
| `currency` | Paramètre | Devise : `CPEUR` (base euro courant) |
| `value` | Donnée | Valeur observée |
| `flag` | Donnée | Complément d'information relative à la valeur |
| `lastupdate` | Donnée | Date de dernière mise à jour |

## Construction des données

Les données sont construites à partir du modèle entrées-sorties multirégional FIGARO et des [comptes d'impacts](/docs/donnees-statistiques/sources) associés aux dimensions de l'Empreinte Sociétale. La démarche générale est décrite dans la [méthodologie](/docs/donnees-statistiques/methodologie).

### Méthodologie

La production des données s’opère en **deux étapes** :

1. La première consiste à construire des *comptes d’impacts directs* également appelés *comptes satellites*.
2. La seconde vise à calculer les *empreintes macroéconomiques* en combinant les données d’impacts directs avec celles du modèle FIGARO.

### Comptes d'impacts

Les comptes d’impacts directs, aussi appelés comptes satellites, décrivent, pour chaque pays, chaque branche d’activité et chaque année, la valeur ou le volume observé ou estimé d’externalités directes mesuré pour un indicateur. Ils concernent par exemple les émissions directes, la consommation d’énergie ou un indicateur social associé aux effectifs. Ces comptes sont construits à partir de sources statistiques diverses (Eurostat, OCDE, Insee, etc.), propres à chaque indicateur, et sont harmonisés pour être exprimés dans la nomenclature utilisée au sein des tables FIGARO (i.e. ventilation en 64 branches et 50 pays/régions du monde). Lorsque des valeurs sont manquantes ou atypiques, des traitements de nettoyage ou de remplacement peuvent être appliqués, afin d’obtenir des séries cohérentes et exploitables.

Pour les séries historiques, les impacts reprennent les données observées et reflètent ce que les sources statistiques permettent de mesurer sur les années passées.

### Construction des empreintes

Si les comptes d’impacts détaillent les externalités directes des différentes branches d’activité, ces dernières induisent également des impacts indirects en amont, liés à leurs consommations intermédiaires et à leurs consommations de capital fixe (immobilisations).

Pour prendre en compte ces impacts amont, l’approche mobilise les tables entrées-sorties FIGARO (Eurostat, JRC). Ces tables annuelles décrivent les flux économiques entre branches et pays : qui achète quoi à qui, pour produire quoi. C’est une photographie de l’économie, qui détaille les interactions des agents sur une période et un territoire donnés. Elles permettent de construire une matrice dite de « Leontief » indiquant l’ensemble des productions nécessaires, directement et indirectement, pour satisfaire une demande ou produire une unité d’activité, pour chaque couple branche/pays. Cette méthodologie est normée et fait l’objet de nombreuses études académiques qui nourrissent nos analyses.

Pour chaque indicateur, on combine alors cette matrice avec un vecteur d’impact (exprimant pour chaque couple branche/pays, la quantité d’impact associée à une unité de production) pour obtenir une estimation des empreintes des activités : **les impacts totaux induits dans l’économie pour produire une unité économique donnée**.

Les empreintes sont produites pour plusieurs agrégats économiques : la production, les consommations intermédiaires, la consommation de capital fixe, et la valeur ajoutée nette.

Enfin, les jeux de données sont structurés selon différentes nomenclatures d’activité pour faciliter leur exploitation :

- A\*64 – Nomenclature FIGARO
- A\*88 – Empreintes par division économique
- A\*38 – Empreintes par branche d’activité

### Désagrégations sectorielles

En complément, un travail de désagrégation sectorielle permet de passer des empreintes produites selon la nomenclature FIGARO (A\*64 activités) à des empreintes plus fines, pour être au plus proche du code APE (A\*732).

La méthode s’appuie sur plusieurs modèles entrées-sorties environnementaux nationaux (modèles EEIO) plus détaillés, tels que ceux du Royaume-Uni (A\*104), des États-Unis (A\*398), du Canada (A\*108) et du Danemark (A\*117). Pour chaque modèle, on étalonne les données avec la France, et on produit les empreintes des activités économiques, selon les mêmes principes présentés ci-avant. Les données obtenues sont ensuite combinées et rapprochées de la nomenclature française, en donnant plus de poids aux correspondances les plus fiables.

Cette approche permet d’obtenir des estimations sectorielles plus fines, cohérentes avec les ordres de grandeur des empreintes obtenues via le modèle FIGARO.

## Accès via l'API

**Endpoint :**

[`https://api.sinese.fr/v2/macrodata/macro_fpt`](https://api.sinese.fr/v2/macrodata/macro_fpt)

Les paramètres de la table s'utilisent comme filtres de requête. Plusieurs valeurs peuvent être séparées par des virgules (ex. `year=2020,2021`). Les résultats sont paginés avec `page` et `limit` (**5 000 résultats maximum** par page).

**Exemple :** intensité d'émission de gaz à effet de serre (`GHG`) observée pour la production (`PRD`) de l'industrie chimique (`C20`) en France (`FRA`) en 2022.

```bash
curl "https://api.sinese.fr/v2/macrodata/macro_fpt?indic=GHG&year=2022&industry=C20&country=FRA&aggregate=PRD"
```

Les paramètres et leurs valeurs possibles sont disponibles via l'endpoint de métadonnées :

```bash
curl "https://api.sinese.fr/v2/macrodata/macro_fpt/metadata"
```

La documentation complète de l'API est disponible sur [api.sinese.fr/docs](https://api.sinese.fr/docs/).
