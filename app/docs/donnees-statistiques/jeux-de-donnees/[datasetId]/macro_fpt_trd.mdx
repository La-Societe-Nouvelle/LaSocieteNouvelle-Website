## Présentation

Le jeu de données **macro_fpt_trd** regroupe les tendances des empreintes des activités économiques selon la nomenclature FIGARO (A*64).

Les empreintes sont disponibles pour les agrégats suivants :

- **PRD** : Production
- **GVA** : Valeur ajoutée brute
- **IC** : Consommations intermédiaires
- **NVA** : Valeur ajoutée nette
- **CFC** : Consommations de capital fixe

Les dimensions extra-financières disponibles sont celles de l'[Empreinte Sociétale](/docs/empreinte-societale/indicateurs).

La période de tendance couvre de 2022 à 2030. La date de début de la série correspond à l'année suivant la dernière année observée.

Les empreintes sont exprimées **en euros courants**, et **dans l'unité par défaut de l'indicateur**.

## Description de la table

Paramètres du jeu de données :

- **indic** : Code de l'indicateur au sein de l'Empreinte Sociétale
- **year** : Année
- **area** : Code du pays (ISO3) ou région du monde
- **industry** : Code du secteur, selon la NACE Révision 2 (Codes A64, A21 et A10)
- **aggregate** : Code de l'agrégat économique

Autres colonnes :

- **value** : Valeur observée
- **flag** : Complément d'information relative à la valeur
- **lastupdate** : Date de dernière mise à jour

## Construction des données

Les données sont construites à partir du modèle entrées-sorties multirégional FIGARO et des [comptes d'impacts](/docs/donnees-statistiques/sources) associés aux dimensions de l'Empreinte Sociétale. La démarche générale est décrite dans la [méthodologie](/docs/donnees-statistiques/methodologie).

## Nomenclatures et jeux dérivés

Les données sont également disponibles en nomenclature A\*38 (branche) et A\*88 (division).

Jeux de données dérivés :

- **macro_fpt_trd_a38** : Empreintes macroéconomiques agrégées par branche (A*38)
- **macro_fpt_trd_a88** : Empreintes macroéconomiques étendues par division (A*88)
